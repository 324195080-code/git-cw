Explicar Código

Registra tu edad y te indicará si eres mayor o menor de edad

Código:


    # <stdio.h>

    int main() 
    {
        int edad;
        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);

        if (edad >= 18) 
        {
        printf("Eres mayor de edad.\n");
        } 
        else 
        {
        printf("Eres menor de edad.\n");
        }

        return 0;
    }

Explicación:

Empezamos con: #Include <stdio.h>,
sirve para incluir las bibliotecas

Declaramos una variable de tipo numerica, con el nombre de "edad",
int edad;

Con printf enviamos un mensaje al ususario en estes caso seria preguntando su edad:
printf("¿Cuántos años tienes? ");

Enviamos la edad dada a la direcciión de la variable edad con scanf("%d", &edad);
Nota: %d es una máscara para números enteros

Tenemos una condicional if
En ella evalua si edad es mayor o igual a 18.
if (edad >= 18)
Si es verdad te envia un mensaje diciendo que eres mayor de edad
printf("Eres mayor de edad.\n");
Si es falso "else", te enviará un mensaje que eres menor de edad
printf("Eres menor de edad.\n");

Por último tenemos return 0;ya que nos indica que el código se ejecuto de manerá exitosa
